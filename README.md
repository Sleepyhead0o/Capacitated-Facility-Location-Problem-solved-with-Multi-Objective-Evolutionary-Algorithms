# Capacitated-Facility-Location-Problem-solved-with-Multi-Objective-Evolutionary-Algorithms

This project solves the Multi-Objective Capacitated Facility Location Problem (CFLP) using two Multi-Objective Evolutionary Algorithms NSGA-II and SPEA2.

The two objectives are to minimize the facility-opening cost and the customer-allocation cost.              

## How to start the project
git clone git@github.com:Sleepyhead0o/Capacitated-Facility-Location-Problem-solved-with-Multi-Objective-Evolutionary-Algorithms.git <br/>

cd Capacitated-Facility-Location-Problem-solved-with-Multi-Objective-Evolutionary-Algorithms <br/>

conda env create -f env.yml <br/>

conda activate cflp-moea <br/>

python main.py <br/>
